promo-build — Estrera Botanicals 60s promo (ITS 303 Animation)

Everything here is additive: the pipeline regenerates its own outputs in place
and never deletes anything. Debug artifacts (smoke tests, probe logs, AE boot
logs) are intentionally kept.

What this builds

A ~60 s, 1920x1080 @ 30 fps motion-graphics promo of the Estrera Botanicals
site (Route B — no screen recordings): 9 scenes, palette and fonts taken from
the shipped site CSS (assets/styles/app.css: dark green #2B502E, light
green #83A27E, dirty white #F9F5EC; DM Serif Display + Plus Jakarta Sans).

Scene timing: intro 0-5, hero 5-12, essentials 12-18, shop 18-27, cart 27-34,
payments 34-45, order+pipeline 45-53, account 53-57, end card 57-60.

v3 — the real site in the video (superseded by v4, Nov 11)

v3 replaces the reconstructed art with the actual website: the 15 desktop
screenshots pasted into the vault note are cropped to bare page content and
animated inside a drawn browser frame. Journey follows the captures:
Blooming Mama Oil -> checkout P54 -> order #00009 (Pending).

pathwhat it is
crop_shots.mjscrops page content out of the vault screenshots -> captures_v3\ (exact pixel bounds documented in-file: nav starts y=122, profiler starts y=1396, sidebar ends x=51, right trimmed 24px for the overlay scrollbar)
captures_v3\*.png14 page captures at 2079x1268 + payments_closeup.png (506x477, already clean)
render_frames_v3.mjsv3 renderer — same engine/timings/captions as v2, scenes 2-8 composite the captures (node render_frames_v3.mjs qc 255,660 renders just those frames to render\qc_v3\ for checks; no args = full 1800)
render/frames_v3\v3 frames
render/Estrera_Promo_v3_60s.mp4v3 video (also copied into the vault as atatchments\Estrera Promo Video v3.mp4)
build_promo_v3.jsxAE project from the real captures: each scene = bg + browser chrome shapes + capture layers (rounded-rect track mattes, zoom/focus keyframes mirroring drawPage) + captions; saves Estrera_Promo_v3.aep, stays open, no auto-render

Blend rule learned in QC: when one capture fades in over another, both must
draw at the SAME zoom/focus (backgrounds align, only the modal dissolves), and
a same-image zoom must be a single animated draw (crossfading two framings of
one page double-exposes every element).

powershell
node render_frames_v3.mjs                               # full 1800 frames
bin\ffmpeg-9.0.2-essentials_build\bin\ffmpeg.exe -y `
  -framerate 30 -i render\frames_v3\frame_%04d.png `
  -c:v libx264 -preset medium -crf 18 -pix_fmt yuv420p `
  -movflags +faststart render\Estrera_Promo_v3_60s.mp4

v4 — the living-elements rebuild (current, Nov 11)

Feedback on v3 was that it plays as a slideshow: static page captures with zooms
and dissolves. v4 keeps the same 9 shots, timings, captions, browser frame and
captured journey (Blooming Mama Oil ₱54 → checkout → order #00009 Pending), but
rebuilds every captured page as living UI elements — nav, product cards,
buttons, tiles, modals are drawn fresh each frame, so interactions are real:
a cursor travels/hovers/presses (dip + ripple), cards lift on hover, the cart
and confirm modals pop with overshoot, radio options fill on selection, and the
home/checkout pages scroll as actual content with a sticky nav. Screenshots are
the blueprint, not the footage. Silent by design — add music, export via AE.

pathwhat it is
v4_lib.mjsv4 engine — timing helpers, primitives, browser chrome, the hold-then-travel cursor (drawCursor: keys are ARRIVAL times, 45% hold then easedIO arc; click = dip + ripple; out = fade), asset loader
v4_pages.mjspage painters — home/shop/checkout/summary/account + cart/success/confirm modals + the status pipeline (content-local 0..1400 × 0..854, sticky nav painted last over scrolled content)
render_frames_v4.mjsv4 scenes + loop — scroll curves, cursor keys, selection story (COD→GCash@39.0→Card@40.4→COD@41.7), fixed crossfade (incoming scene pre-rolls from t0 − 0.4 with complementary alphas, no 1-frame dip)
render/qc_v4/QC stills (node render_frames_v4.mjs qc ≈ 15 s; qc <frameNo> for specific frames)
render/frames_v4\v4 frames — 1800 PNGs (1920×1080 @ 30 fps, 60 s), ~7 min render
render/Estrera_Promo_v4_60s.mp4v4 video (also copied into the vault as atatchments\Estrera Promo Video v4.mp4)
build_promo_v4.jsxAE project hosting the finished sequence (imports frames_v4 as footage, stretch-normalized to 30 fps via layer.stretch, 9 shot markers, saves Estrera_Promo_v4.aep, stays open, no auto-render)
assets/v4/element crops used by the painters (concern ×2, avatars ×3, profile)

QC loop notes: cursor teleport → hold-then-travel rewrite; scroll translate +
nav painted last (content slid over the sticky nav); modals moved inside the
content clip (dim covered the whole canvas, not the viewport); hover windows
retimed to cursor departures; plus-icon/label overlap on the dashed "Other
Payment Methods" button. All verified against 60+ spot frames incl. the
S2→S3 seam.

AE note: layer.stretch is a Layer attribute, not a timeline property
(layer.property("Stretch") is null → "null is not an object"). Bootstrap
quirk: its flag-rename silently fails while the stale render\run_now.used.flag
destination exists, so the flag stays readable (this is what makes repeated
boot-runs work) — after a successful build the flag is moved by hand to
render\run_now.used_v4.flag to disarm double-firing.

Requirements (all already in place): Node 24 + @napi-rs/canvas (npm i in this
folder), fonts shipped inside assets/fonts (registered directly from TTF, no
system install needed for node; they were also installed per-user for AE).

After Effects project for sound editing (the v2 flow — current, Nov 9)

The user-facing path: AE builds the project file and stays open, user adds
music, exports via Media Encoder.

  1. build_promo_v2.jsx (in promo-build\) builds all 9 scene comps + master
    Estrera Promo 60s, saves promo-build\Estrera_Promo.aep, opens the master
    in the viewer, and leaves AE open. No render, no quit — the user adds
    sound themselves. Hardened vs v1: no app.newProject() (the call that
    crashed AE headless), null-fill-safe shape helper, log + alert with paths on
    any error. v1 (build_promo.jsx) stays untouched as an artifact.
  2. To run it again any time: AE File > Scripts > Run Script File… →
    promo-build\build_promo_v2.jsx (run it once per fresh AE session; running
    twice stacks duplicate comps in the same project — harmless but messy).
  3. The auto-run path: AfterFX.exe launch + run_now.flag (content names the
    script) through the Startup bootstrap. After a successful build the flag is
    renamed to run_now.used_v2.flag so it never double-fires.
  4. Adding sound (the user's workflow):
    • File > Import > File… → pick music (mp3/wav)
    • drag it into the Estrera Promo 60s timeline below the video layers, at 0:00
    • trim/fade to taste (60s; the end card starts at 57s — fade out under it)
    • File > Export > Add to Adobe Media Encoder Queue → H.264, 1920×1080, 30fps
  5. If text shows in a wrong font instead of DM Serif Display / Plus Jakarta
    Sans (postScriptName resolution is AE-version picky): select the text
    layers, pick DM Serif Display / Plus Jakarta Sans in the character
    panel — everything is already placed/timed, only the face may need a swap.
    The build log records which postScriptName each family resolved to.

After Effects headless + one-click fallback (original, for the record)

AE 2026 headless (-noui -r) crashes at app.newProject() on this machine
(exit 1, GPU3 warning in stderr) and -r scripts are silently refused — that's
why the canvas pipeline carries the video deliverable. build_promo.jsx (v1)
remains as the AE-native design source it was written from. The bootstrap
opencode_promo_build.jsx in AE's Scripts\Startup folder is flag-gated: it
does nothing unless promo-build\run_now.flag exists. render/ae_boot_seen.txt
proves the bootstrap ran on any AE launch.

House rules honored

  • No file is deleted by this pipeline; superseded artifacts are kept (zip,
    debug logs, both test scripts).
  • Attention: python notify.py "OpenCode" "message" — launched only via
    detached Start-Process so it doesn't block the shell.

Native editable AEP (v4 mirror) - build_promo_v4_native.jsx

Builds Estrera_Promo_v4_native.aep: a fully editable AE project mirroring the
flattened v4 render shot for shot (same 9 shots, timings, captions). Master comp
Estrera Promo v4 60s (1920x1080 30fps 60s) + 9 scene comps; 5 page precomps +
3 modal precomps (1400x854/3020x1250, canvas-local coords) carry all interaction
keyframes at v4's exact times; real shape/text layers, browser chrome (bar mask
r18, tab-strip masks, viewport matte), cursor rigs with hand/arrow swap + ripples.

Re-run: write run_now.flag (content = build_promo_v4_native.jsx) in the
promo-build folder, then restart AE - the Startup bootstrap evals it. Watch with
render/watch_v4_native.ps1 (log render/build_v4_native_log.txt; success =
DONE. + AEP exists). Run once per fresh AE session (duplicate comps otherwise).

AE scripting traps encoded in the script (do not regress):

  • Shape attrs validate on assignment: build local arrays, assign once.
  • Mask add: Masks.addProperty("ADBE Mask Atom"), path via ADBE Mask Shape.
  • layer.parent = X is world-preserving (offsets frozen at set time) - parent
    BEFORE keying the parent's motion (pipeline/cursor rigs rely on this).
  • addProperty on an indexed group invalidates sibling property refs - re-fetch
    before keying (intro rule).
  • Dashes: add ADBE Vector Stroke Dash/Gap 1 items before setting values.
  • 2D properties (Scale/Position) need array values, never scalars.

Music + export: same as the v4 pipeline (add audio in Estrera Promo v4 60s
at 0:00, fade ~0:57, Add to Adobe Media Encoder Queue, H.264 1920x1080 30fps).
QC beats against render/Estrera_Promo_v4_60s.mp4.
