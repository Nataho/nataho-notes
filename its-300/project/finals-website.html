Grading rubric

arrived 2026-11-10 — machine-extracted to Rubrics for Final Project (extracted text), PDF is the source of truth. 100 points:

#CategoryPts
1Authentication & User Roles (login/logout 6, hashing 5, roles 4, unauthorized blocked 2)17
2Authorization & Access Control (route protection 5, 403/redirect 3, role checks in controller + templates 3)11
3Admin Features (create users 5, update 4, delete 4, view all records 3, dashboard totals 3)19
4Staff Features (create records 6, edit own 6, view 4 — no admin pages)16

Mandatory functions (pass requirement)

  • Admin: login/logout, change own password, own profile; staff-account CRUD (create admin+staff, edit name/email/role, reset password, delete with confirmation, disable/archive); dashboard totals; view/edit/delete ANY record + search & filter; admin routes protected at 3 layers (security.yaml, controller checks, Twig menu).
  • Staff: login/logout, own profile, change own password; create records; view (own/shared); edit own only; delete own only with confirmation; must NOT create accounts, reach dashboard, delete users, or change roles — URL bypass must 403 or redirect.

Likely point-losers to check first: delete-with-confirmation on both sides, edit-own-records enforcement, disable/archive accounts, admin search & filter, role-based Twig menu.

Batch 7g landed 2026-11-12 — the account page sideways-scroll root fix + wrapping chip grid, from the user's follow-up ("why is the mobile view of accounts landscape… put it on the side bar… how to make it cleaner?").
