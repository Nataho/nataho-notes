Problem to be solved

  1. Orders are handwritten in a logbook + paper receipts → poor records
  2. Item counts are not verified → customers claim items are lost
  3. Unclaimed / unpaid customers must be chased by manually searching phone numbers
  4. Daily sales are added up by hand
  5. Customers have no way to know when their laundry is ready

Functional features

  1. Record orders online — pick service, weigh, item counts, auto price
  2. Track laundry steps — Washing → Drying → Folding → Ready
  3. Count specific clothes — exact number + type per order
  4. Track payments — Paid / Unpaid ("wash now, pay later")
  5. Automatic SMS — ready for pickup, power outage, unclaimed reminders
  6. Daily & monthly sales reports — Owner/Admin only
  7. Customer online checker — status + amount due on their phone
  8. Project Assistant — restricted teammate chat with the model, notes sync, two judges, magic-word publish, owner inbox (experimental)

Constraints

  • Web App + Android App; no iOS (framework is Android-only) — iPhone users use the web app
  • Server kept at the shop (local Wi-Fi keeps working); internet needed for SMS + remote checking
  • Thermal receipt printer support; simple video tutorial
  • Everyone logs in; customers see only their own tickets; workers only their orders; Manager sees all orders but not finances; only Owner/Admin sees money
  • Cannot delete an order that still has an unpaid bill
